همراه من — نسخه ارتقایافته وب‌اپ
================================

ویژگی‌ها:
- نمودار درآمد و هزینه برای ۶ ماه اخیر، بر اساس تراکنش‌های ثبت‌شده
- نمودار دایره‌ای پیشرفت کارها
- ۵ پوسته: روشن، تیره، اقیانوسی، رز و نعنایی
- ورود تاریخ‌ها در فرم‌ها با تقویم شمسی (فرمت نمونه: ۱۴۰۵/۰۷/۲۰)
- آیکون‌های وب‌اپ و تنظیمات نصب روی صفحه اصلی موبایل
- ذخیره‌سازی محلی در مرورگر؛ اطلاعات در همان دستگاه/مرورگر می‌ماند

نصب روی GitHub Pages:
1. فایل ZIP را از حالت فشرده خارج کن.
2. تمام فایل‌های داخل پوشه را در ریشه مخزن GitHub بارگذاری و فایل‌های قبلی را جایگزین کن.
3. Commit changes بزن و حدود 1 تا 3 دقیقه صبر کن تا GitHub Pages به‌روز شود.
4. لینک سایت را با Chrome در اندروید باز کن؛ از منوی سه‌نقطه گزینه «Install app / نصب برنامه» یا «Add to Home screen / افزودن به صفحه اصلی» را بزن.
5. اگر نسخه قدیمی باز می‌شود، سایت را یک‌بار ببند و دوباره باز کن یا داده/کش سایت را در Chrome پاک کن.

نکته‌ها:
- این یک PWA است، نه APK مستقل؛ از طریق Chrome نصب می‌شود و آیکون دارد.
- نصب نیازمند HTTPS است؛ GitHub Pages به‌صورت معمول HTTPS ارائه می‌دهد.
- نمودارها بر اساس اطلاعات واردشده‌اند؛ اگر تراکنش یا کاری ثبت نشده باشد، نمودار خالی/صفر می‌ماند.
- تاریخ‌ها برای ورود با فرمت شمسی هستند؛ داده‌ها برای محاسبه و سازگاری در قالب تاریخ استاندارد ذخیره می‌شوند.
- اطلاعات مهم را از بخش پشتیبان‌گیری خروجی بگیر؛ پاک‌شدن داده‌های مرورگر ممکن است اطلاعات محلی را حذف کند.
