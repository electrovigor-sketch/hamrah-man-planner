همراه من — بسته وب‌اپ قابل نصب (PWA)

فایل‌های این بسته:
- index.html: برنامه اصلی
- manifest.json: نام، رنگ، حالت اجرای مستقل و آیکون‌های نصب
- sw.js: ذخیره فایل‌های برنامه برای بازشدن آفلاین پس از بارگذاری اولیه
- icon-192.png و icon-512.png: آیکون‌های برنامه
- icon-maskable-512.png: آیکون سازگار با شکل‌های مختلف آیکون اندروید

نصب روی GitHub Pages:
1) از مخزن فعلی GitHub خود یک نسخه پشتیبان بگیر یا دست‌کم فایل‌های فعلی را دانلود کن.
2) تمام فایل‌های داخل این پوشه را در ریشه مخزن (همان جایی که index.html فعلی قرار دارد) بارگذاری کن؛ فایل‌های هم‌نام را جایگزین کن.
3) تغییرات را با Commit changes ثبت کن و منتظر بمان GitHub Pages منتشر شود.
4) آدرس سایت را در Google Chrome اندروید باز کن. از منوی سه‌نقطه گزینه Install app یا Add to Home screen را انتخاب کن.
5) برنامه را از آیکون صفحه اصلی باز کن. در حالت standalone نوار آدرس مرورگر نمایش داده نمی‌شود.

اطلاعات:
- داده‌ها در حافظه محلی مرورگر همین دستگاه ذخیره می‌شوند و به‌طور خودکار بین دستگاه‌ها همگام‌سازی نمی‌شوند.
- از داخل بخش «بیشتر ← پشتیبان‌گیری» مرتب فایل JSON بگیر و آن را در جای امن نگه دار.
- پاک کردن داده‌های سایت/مرورگر ممکن است اطلاعات محلی را حذف کند.
- پس از انتشار نسخه جدید، اگر برنامه هنوز نسخه قبلی را نشان می‌دهد، برنامه را کامل ببند و دوباره باز کن. در صورت نیاز، اطلاعات را پشتیبان بگیر و سپس کش/داده سایت را پاک و دوباره نصب کن.
- نصب PWA به HTTPS نیاز دارد؛ GitHub Pages این شرط را فراهم می‌کند.
- اجرای آفلاین برای فایل‌های ذخیره‌شده در کش فراهم است؛ قابلیت‌هایی که به اینترنت یا مجوزهای سیستم‌عامل نیاز دارند ممکن است آفلاین کار نکنند.
