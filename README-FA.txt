همراه من — پلنر فارسی زندگی و کسب‌وکار
======================================
فایل‌های این بسته:
- index.html : برنامه کامل
- manifest.json : مشخصات نصب وب‌اپ
- sw.js : کش آفلاین و به‌روزرسانی
- README-FA.txt : همین راهنما

راه‌اندازی روی GitHub Pages با گوشی:
1) در GitHub یک مخزن جدید با نام hamrah-planner بساز.
2) ZIP را روی گوشی از حالت فشرده خارج کن.
3) چهار فایل را در ریشه مخزن آپلود کن و Commit changes را بزن.
4) Settings > Pages > Build and deployment را باز کن.
5) Source = Deploy from a branch، Branch = main، Folder = /(root)، سپس Save.
6) پس از آماده‌شدن انتشار، آدرس https://USERNAME.github.io/hamrah-planner/ را باز کن.
7) در Chrome منوی ⋮ > Add to Home screen را بزن تا میانبر شبیه اپ داشته باشی.

مهم:
- اطلاعات در حافظه محلی مرورگر ذخیره می‌شود. فایل پشتیبان JSON را مرتب دانلود کن.
- فایل پشتیبان رمزگذاری نشده است؛ آن را محرمانه نگه دار.
- اعلان‌های مرورگر به اجازه کاربر و محدودیت‌های سیستم‌عامل/مرورگر وابسته‌اند و تضمین اعلان سیستمی نیستند.
- تاریخ‌ها در فرم‌ها از قالب تاریخ دستگاه/مرورگر استفاده می‌کنند؛ نمایش تاریخ شمسی است.
- فروش ثبت‌شده موجودی کالا را کم می‌کند. حذف فروش، موجودی را به‌صورت خودکار برنمی‌گرداند؛ در صورت نیاز موجودی را دستی اصلاح کن.
